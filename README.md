## Architecture principles I value

- Start with business constraints, not technology trends
- Prefer evolutionary architecture over big-bang rewrites
- Use microservices only when the team and domain are ready
- Make architecture decisions explicit and reviewable
- Treat AI as an engineering capability, not just a coding shortcut
- Optimize for maintainability, delivery flow, and operational clarity
